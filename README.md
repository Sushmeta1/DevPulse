# DevPulse — AI-Powered GitHub Activity Dashboard

## Live Demo
Coming soon — Railway deployment in progress

## Tech Stack
- Frontend: React 18, Tailwind CSS, Recharts
- Backend: Node.js, Express
- Database: PostgreSQL
- Auth: GitHub OAuth 2.0
- DevOps: Docker, GitHub Actions, Railway

## Local Setup

### Prerequisites
- Node.js 20+
- Docker Desktop
- Git

### Run locally
```bash
git clone https://github.com/Sushmeta1/DevPulse.git
cd DevPulse
cp .env.example .env
# Fill in your values in .env
docker compose up
```
